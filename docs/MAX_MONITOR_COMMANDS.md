# Команды MAX-мониторинга

Версия 0.13.2, 1 ноября 2026, Europe/Moscow. Все команды и ответы — в одном
закрытом solo-чате `monitoring_proekts_control`. Работа ведётся в отдельной копии.
Новый набор требует явного допуска DOM v2; прежние конфигурации с тремя командами
не расширяются автоматически.
В этой копии допуск уже выполнен: живая приёмка покрыла все 17 действий.

Команды отправляют обычным отдельным сообщением, без цитаты, пересылки или правки.
Команда `команды` выводит актуальную справку только по разрешённым действиям.

| Команда | Назначение |
| --- | --- |
| `команды` | разрешённые команды и ограничения |
| `статус` | сохранённое состояние проекта |
| `резерв` | готовые статьи и цель резерва |
| `ошибки` | текущие препятствия и последние пять сохранённых отказов кандидатов |
| `источники` | источники и действующие фильтры |
| `пополни резерв до N` | подготовка до цели от 1 до 12 без отправки статей |
| `задачи` | последние 10 заданий пополнения |
| `задача ID` | состояние задания по ID |
| `отмени задачу ID` | отмена ожидающего задания; у выполняющегося — запрос остановки будущих проходов |
| `продолжи подготовку` | возобновить только разрешённые будущие проходы пополнения |
| `продолжи проект` | снять общую паузу только при паузе всех адресатов, без включения отправки |
| `диагностика` | готовность зависимостей без запуска перевода/отправки |
| `пауза [подготовки\|TARGET_ID]` | пауза проекта, пополнения или адресата |
| `сверь DISPATCH_ID` | сверить прежнюю попытку без новой отправки |
| `сними блокировку TARGET_ID` | диагностика без сброса защиты и неизвестного исхода |
| `добавь источник https://example.org/section/` | кандидат на проверку прав; URL не загружается и источник не включается |
| `измени фильтр ключевые слова: слова` | точное предложение фильтра с отдельным подтверждением на паузе |

`ID` — полный номер задания из ответа `задачи`; `TARGET_ID` — точный адресат
из статуса; `DISPATCH_ID` — номер сохранённой отправки; `TOKEN` — одноразовый
токен показанного предложения фильтра. У фильтров два варианта: `измени фильтр
ключевые слова: звёзды, галактики` и `измени фильтр авторы: Имя автора`, затем
`подтверждаю TOKEN` на общей паузе при той же версии настроек.
TOKEN действует 10 минут и связан с этим аккаунтом, чатом и версией настроек.
Слова и имена указываются так, как они записаны в исходном материале.

Для снятия всех ограничений выбранного фильтра: `очисти фильтр ключевые слова`
или `очисти фильтр авторы`, затем подтвердите показанный TOKEN. Очистка также
проходит проверку паузы и отсутствия активных/неизвестных операций.

`пауза подготовки` останавливает будущие проходы очереди, `продолжи подготовку`
продолжает только эту очередь. `пауза` ставит проект и все адресаты на паузу.
`продолжи проект` снимает общую паузу только для подготовки: все адресаты должны
оставаться на паузе, sending/unknown и leases отсутствовать. Отправитель не запускается.

Отмена ожидающего задания окончательна. У выполняющегося сохраняется запрос
отмены: модель/сеть не прерываются, после известного результата останавливаются
следующие проходы. Unknown не превращается в отмену и не разрешает повтор.
Старые отменённые/отклонённые/неизвестные задачи не восстанавливаются продолжением.

Одна новая операция пополнения, продолжения или изменения источников допускается
за отображаемую минуту. Пауза и отмена доступны немедленно. После перепривязки
первую команду отправляют в следующую полную минуту после `primed`.
При превышении лимита приходит однократный ответ с причиной; повторный опрос
того же сообщения не создаёт новую задачу.

Новый источник сохраняется только как `pending_rights`: URL не открывается,
автоматический сбор не включается. Снятие блокировки означает диагностику;
unknown, leases, права и отказы качества не сбрасываются. Сверка отправки не
повторяет Send. Диагностика не запускает перевод, публикацию или пробный пост.

Принятие пополнения не означает готовые статьи: цель выполнена только при полном
проверенном запасе. История подготовки сохраняется; публикации в этой копии на паузе.
Произвольные команды shell/SQL, установка кода и свободные задачи LLM через чат
не выполняются. Ключи и приватные настройки в справку/архив не включаются.
